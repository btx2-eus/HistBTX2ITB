# HistBTX2ITB · irakaslearen atari publikoa

Espainiako Historia, Batxilergoko 2. maila, 2026–27. Atari estatikoa da: `index.html` irekitzen da GitHub Pages-en; `gaitegia.json` fitxategiak USaP/PAUko bederatzi gaien izenburu eta epigrafe ofizialak gordetzen ditu. Une honetan M1eko bederatzi saioak eta bost PDF publiko daude prest. M2–M9 gaitegia dira, ez mintegi osatuak.

## Pribatutasun-muga

Biltegi honetan **ez dago** erabili gabeko azterketarik, ezta irakaslearen erantzun-giltzarik ere. Material horiek sarbide kontrolatuan gorde behar dira. `materialak/` karpetara fitxategi berriak kopiatu aurretik, egiaztatu muga hori.

## Argitaratzeko

1. Igo erroko `index.html`, `styles.css`, `app.js`, `favicon.svg`, `gaitegia.json` eta `README.md`; igo, halaber, `materialak/` karpeta bere bost PDFekin. Mantendu karpeta-egitura bere horretan.
2. GitHuben, biltegiaren **Settings → Pages** atalean, aukeratu `Deploy from a branch`, `main` eta `/ (root)`, erakundearen planak biltegi pribatuaren Pages argitalpena baimentzen badu.
3. Ireki emandako web-helbidea eta egiaztatu 1. gaia, 1. eta 9. saioak, bost PDFak eta sakelako diseinua. GitHub Pages ez badago erabilgarri biltegi pribatuan, ez aldatu biltegia publiko baimen espresurik gabe: biltegi osoaren edukia eta historia zabalduko lirateke.

## Tokian probatzeko

Zerbitzatu karpeta HTTP zerbitzari estatiko batekin; `gaitegia.json` kargatzeko ez da nahikoa `index.html` fitxategia diskoan zuzenean irekitzea.

## Edukiaren hierarkia

- Apunteak: ezagutza historikoaren oinarria (jatorrizko Drive fitxategia).
- Aurkezpena: irakaslearen azalpenaren euskarria (jatorrizko Drive fitxategia).
- Dosierra eta iturriak: banakako ariketa eta autozuzenketarako euskarriak.
- Historia BTX2 weba: kronologia eta PAU entrenamendua.
- M1eko azken produktua: 250–300 hitzeko ohar kuratorial historikoa, ikasleak errubrikaz autoebaluatua; irakaslearen kalifikazioa sei azterketetara mugatzen da.
